# Lore & Echo optional pack catalogue

The approved 40-sound collection is bundled in the app. No new optional worldbuilding packs are approved for publication yet, so catalogue.json deliberately contains an empty pack list. A successful refresh must not substitute procedural test blends for new releases.

Public base URL: https://raw.githubusercontent.com/SADStudios/dungeon-echo-sound-packs/main/catalogues/v1/

Publish approved media and artwork first using immutable versioned filenames and verified sizes/SHA-256. Update catalogue.json last. Preserve existing IDs, references, assets and release URLs. The five proposed packs require audio approval and complete redistribution records before inclusion. No GitHub Actions are required.
